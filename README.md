# カイタイ事務（試作版）

解体業者向けの事務自動化ツールです。物件情報を **1回入力** するだけで、次の書類と期限管理が自動で作られます。

| タブ | できること |
|---|---|
| ① 案件入力 | 施主・建物・現場条件・アスベスト・工期を入力（自動保存） |
| ② 期限・チェック | 築年からのアスベスト含有判定、リサイクル法届出、アスベスト報告、近隣挨拶、道路使用許可、滅失登記などの期限を自動計算 |
| ③ 見積書 | 構造×坪単価、手壊し・狭小道路割増、付帯工事、アスベスト除去、諸経費、消費税まで自動計算 |
| 💰 利益チェック | 人工・重機・ダンプ台数・品目別処分費・ガードマン・アスベスト外注を積み上げ、鉄スクラップ売却を差し引いて粗利を計算。**値引きできる上限**と赤字ラインを表示。マニフェストの処分代と経費の実績から、実際の利益も表示 |
| 📅 工程表 | 構造・坪数・付帯工事から工程と日数を自動で組み、日曜休工で日付入りの工程表を作成 |
| 🚛 マニフェスト | 搬出ごとの紙・電子マニフェストを登録。B2・D票（90日／特管60日）、E票（180日）、電子の登録期限（3日）を自動計算し、全案件の返送漏れを警告。見込みと実績の比較、交付等状況報告書（6月30日期限）の集計。ゴミの種類ごとの処分単価から処分代を自動計算。処分場ごとの単価表を登録でき、処分業者を選ぶとその単価を使用（1枚ごとの手入力が最優先）。種類ごとに一番安い処分場を表示。処分場ごとの締め日（1〜28日・末日）で、全現場の処分場ごとの請求を締めごとにまとめて表示 |
| ⛽ 経費 | 消耗品・高速代・燃料費・その他を現場ごとに記録。項目別合計と、処分代を含めた月ごとの全現場まとめ |
| 🚜 リース | 重機・ダンプのリースを日額・月極・切替日数・回送費で登録。月（区切り）ごとに使った日数が決めた日数を超えたら月極、超えなければ日割り（区切りはリース会社ごとの締め日〈1〜28日・末日〉、借りた日から1か月、30日ごとから選択）。月極が近い機械や、あと少し借りた方が安くなる機械を全案件で警告。締めごと（月ごと）の請求額、月が変わって日割りに戻ったときの案内、工事の完了予定日まで借りた場合の見込みを表示。月ごとのまとめにリース代を計上 |
| ④ リサイクル法 届出下書き | 届出に転記する項目一式＋委任状 |
| ⑤ 近隣挨拶文 | そのまま配れる挨拶文 |
| ⑥ 取毀証明書 | 施主の建物滅失登記用 |
| ⚙ 設定 | 会社情報・単価表、データのバックアップ／読み込み |

## ネット保存（Supabase）

- `config.js` の Supabase に、メールアドレスとパスワードでログインして使います。入力した内容は自動で保存され、ほかの端末でも同じデータが見られます
- 表の定義は `supabase/schema.sql`。本人のデータしか読み書きできない設定（Row Level Security）にしています
- 新しいアカウントの登録は締め切っています。ログインする人は Supabase の管理画面（Authentication → Users → Add user）で追加します
- 計算（リース・マニフェストの期限、毎朝の通知文）は `core.js` にまとめ、画面と通知で同じものを使います

## 使い方

`index.html` をブラウザで開くだけです（インストール・サーバー不要、スマホでも利用可）。
各書類は「印刷 / PDF保存」ボタンでA4に印刷、またはPDFとして保存できます。

- データはその端末のブラウザ内にのみ保存されます。定期的に「データを書き出し」でバックアップしてください。
- 単価・廃棄物量の初期値は相場の目安です。必ず自社の値に変更してください。
- 届出の提出は各自治体の正式様式で行ってください（このツールは転記用の下書きを作ります）。
