# カイタイ事務 — 収益化と営業の計画

## 1. 誰の、何を解決するか

| 項目 | 内容 |
|---|---|
| ターゲット | 従業員1〜20名の解体業者（社長が事務も兼ねている、または事務員1名） |
| 困りごと | 見積書・建設リサイクル法の届出・アスベスト報告・挨拶文・取毀証明書を、案件ごとに毎回手で作っている |
| 解決策 | 物件情報を **1回入力** → 必要書類が **全部自動で出る**、期限も自動で管理 |
| 一言でいうと | 「現場から帰って30分かかっていた事務が5分で終わる」 |

競合は大手向けの建設業管理ソフト（高い・機能過多）と、Excelの自作テンプレート（属人化・期限管理なし）です。
「解体専用」「安い」「スマホで完結」の3点で差別化します。

### いちばんの売り：「見積を出す前に、その現場で儲かるかが分かる」
書類作成だけのソフトは他にもありますが、解体特有の原価（人工・重機回送・ダンプ台数・品目別の処分費・
ガードマン・アスベスト外注）を積み上げ、**鉄スクラップの売却益まで差し引いて粗利を出す** ものはほぼありません。

- 相見積もりで値引きを迫られたとき、**「いくらまでなら下げていいか」がその場で分かる**
- 赤字ラインが見えるので、安請けによる赤字現場を防げる
- 工程表も同時にできるので、届出の添付書類と施主への説明が一度に終わる

営業では「書類が速くなる」より、**「この現場いくら儲かるか、見積の前に分かります」** を先に言う。

## 2. 収益化モデル

### 段階1：手売り＋代行（0〜3か月目）— まず現金を作る
試作品をそのまま売るのではなく、**「書類作成代行サービス」として人力＋ツールで提供** します。

- 届出書類一式の作成代行：**1件 5,000〜10,000円**
- 見積書テンプレート・単価表の初期設定：**30,000円（1回）**
- ツールは自分が使う裏方として利用 → 業者の本当の困りごとを学ぶ

> 目標：解体業者3社と取引、月10万円

### 段階2：月額サブスク（4〜12か月目）
ツールを業者自身が使えるクラウド版にして月額課金に移行します。

| プラン | 月額（税抜） | 内容 |
|---|---|---|
| ライト | 4,980円 | 見積書・挨拶文・取毀証明書、案件数無制限 |
| スタンダード | 9,800円 | ＋届出下書き・期限通知（LINE/メール）・複数端末 |
| プロ | 19,800円 | ＋マニフェスト管理・原価/利益分析・事務員アカウント |
| 届出代行オプション | 1件 5,000円 | 書類の作成・提出まで丸ごと |

> 目標：有料30社 × 平均9,800円 ＝ **月約30万円**（年360万円）

### 段階3：周辺収益（2年目以降）
- **空き家解体の見積もりサイト**を施主向けに作り、登録業者へ案件を紹介 → **紹介料 成約額の3〜5%** または1件1〜3万円
  （解体1件100〜300万円なので、1件で数万円になる）
- 自治体の **空き家解体補助金** の申請サポート（施主向け）
- 産廃処理業者・スクラップ買取業者との提携による送客手数料

> 解体業者数は全国で数万社あり（解体工事業登録＋解体工事の建設業許可）、まず1つの地域で深く取るのが現実的です。

## 3. 営業のやり方

### ステップ1：知り合い・地元から5社に話を聞く（最初の2週間）
- 地元の解体業者をGoogleマップで「解体」と検索して一覧化 → 電話 or 直接訪問
- 売り込まずに **「事務で一番面倒なことを教えてください」** とヒアリング（15分）
- 聞くこと：月の案件数、届出は誰がやっているか、見積書は何で作っているか、困っている書類、払える金額
- その場で試作品に1件入力して見積書を出して見せる（デモが一番効きます）

### ステップ2：無料で1か月使ってもらう（3〜6週目）
- 3社に **無料で実際の案件で使ってもらう**、代わりに感想と単価表をもらう
- 自治体ごとの届出書式の違いを集めて対応 → これが他社に真似されにくい資産になる
- 「何分短縮できたか」を数字で記録（営業資料にそのまま使える）

### ステップ3：紹介と業界団体で広げる（2か月目〜）
解体業は横のつながりが強い業界です。広告より紹介が効きます。

- 満足した業者に **紹介特典**（紹介した側・された側ともに1か月無料）
- 都道府県の **解体工事業協会** の会合・講習会で事例紹介させてもらう
- 産廃処理場・重機リース会社・行政書士と提携（彼らは解体業者と毎日接点がある）
- 行政書士には「届出代行の前段の書類作成を効率化するツール」として売る道もある

### ステップ4：ネット集客（並行して）
- 「建設リサイクル法 届出 書き方」「取毀証明書 書式」「解体 見積書 テンプレート」など、
  業者が検索するキーワードでブログ記事＋無料テンプレートを配布 → 登録してもらう
- YouTube/Instagramで「解体屋の事務を5分で終わらせる」系の短い動画

### 営業トーク例
> 「社長、見積書と届出の書類、現場から帰ってから毎回作ってますよね？
> 住所と坪数を1回入れるだけで、見積書もリサイクル法の届出もご近所挨拶の紙も全部出るものを作りました。
> 1件だけ今やってる現場で試してみませんか？ お金はいりません。」

## 4. 最初の90日でやること

| 期間 | やること | 成果の目安 |
|---|---|---|
| 1〜2週 | 5社ヒアリング、試作品デモ | 困りごとリスト、協力業者2〜3社 |
| 3〜6週 | 無料試用、自治体書式に対応、単価を実データ化 | 導入事例1件、時短データ |
| 7〜10週 | 代行サービスで有料化（1件5,000円〜） | 初売上 |
| 11〜13週 | クラウド化（ログイン・データ保存・通知）の開発開始 | 月額プランの事前予約 |

## 5. 注意点（法律・リスク）

- **官公署への提出書類の作成を「業として」報酬を得て代行するのは行政書士の業務** です（行政書士法）。
  届出の作成代行で報酬を受け取る場合は、行政書士と提携するか、業者自身が作る「ツール」として提供する形にしてください。
- アスベスト事前調査は有資格者でないとできません。ツールは「結果を入力して書類にする」役割にとどめる。
- 単価・廃棄物量の自動計算はあくまで目安。最終確認は業者が行う旨を表示する。
- 業者の顧客情報（施主の住所・氏名）を扱うため、クラウド化の際はセキュリティと利用規約・プライバシーポリシーを整備する。
